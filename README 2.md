# Hi, I'm Rayavarapu Manohar 👋

### AI/ML Engineer · Multi-Agent Systems · LLM Orchestration · Voice AI

I design and ship production agentic AI systems. For 2+ years I've worked across travel, fintech and healthcare: multi-agent platforms on **Google ADK, LangChain and LangGraph**, agent-to-agent collaboration over the **A2A protocol**, tool integration through **MCP servers**, real-time **voice agents with ElevenLabs and Twilio**, and **Agentic RAG** pipelines that turn financial documents into answers and charts.

- 🧭 **Now:** AI/ML Engineer (Multi-Agent & Voice AI) at Mondee Inc. (now Tabhi), building an end-to-end AI travel assistant for search, booking, changes and the full trip lifecycle
- 🔊 Real-time telephony agents with streaming TTS and human-handoff for high-risk actions
- 📄 IEEE-published author in deep learning for medical imaging (AIMLA 2024)
- 🎓 B.Tech in Artificial Intelligence and Data Science, KITS Coimbatore

| [**Tool-gate**](https://github.com/Manohar8142/Tool-gate) | Runtime per-action authorization for AI agent tool calls: deny / allow / ask policies with session taint tracking. Works with Claude Code, MCP and any agent framework. | Python · MCP · policy engine |
